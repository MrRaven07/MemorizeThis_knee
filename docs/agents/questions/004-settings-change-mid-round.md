# 004 — Changing settings mid-round

- **Status:** answered
- **Asked by:** manager (pre-flight review) · **Date:** 2026-11-10
- **Plan / task:** plan-1 task 10

## Question
The settings drawer can be opened during a round. Should changes apply immediately?

## Why it matters
Changing the timer mid-round would make results meaningless.

## Answer
(manager) New settings apply from the next `ready` phase. The round in progress is never changed. Games take a snapshot of their settings when a round starts.
