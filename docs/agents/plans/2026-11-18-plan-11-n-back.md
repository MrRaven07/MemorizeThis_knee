# Plan 11 — N-Back Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** N-back working-memory drill (position / digit / dual), adaptive N. **Ruling:** `docs/agents/questions/014` (binding). Follows the add-minigame skill. Branch `feat/n-back` from `feat/android`.

## Constraints (from 014)
- Settings: `mode` position|digit|dual (default position), `trialMs` 1500–4000 step 250 (default 2500), `feedback` (default on), `upAfter` 3–5 (default 3). Stimulus visible 500 ms per trial.
- Trials per round = 20 + N. Exactly 6 targets per stream among trials ≥ N; non-targets never match N back; dual streams independent.
- Timing: one `useCountdown` of trials × trialMs; trial index and stimulus visibility derived from elapsed time (no drift, pauses when hidden).
- Accuracy = hits / (hits + misses + false alarms), summed over streams. ≥ 0.8 success (counts up); < 0.5 level −1; otherwise stay and reset the streak. N 1–9, start 2. Level per mode, key `n-back:<mode>`.
- Keys: Space/M (single), A/L (dual); no Enter for matches. One press per stream per trial; buttons disabled for the first N trials. Feedback ✓/✗ plus colour.
- Summary headline `best N=<n> (<mode>)`; stats: Rounds, Highest N per played mode, Accuracy (last 10), Success (last 20).
- Docs: decisions log + a memory-theory section; never `docs/n-back/`.

## Review Focus
1. Generated streams have exactly 6 targets and no accidental matches (many seeds, all N).
2. Pressing never doing anything still scores 0 (not 70%).
3. No double press per trial / no presses during the first N trials.
4. Hidden tab pauses the round; timing stays aligned across 29 trials.
5. Mode levels are independent.
